# gitau-website

Marketing site for [gitau](https://github.com/sn0w12/gitau), a cross-platform Git desktop client. Astro, Tailwind v4.

## Commands

```bash
npm install
npm run dev            # local dev server
npm run build          # static build to dist/
npm run preview        # serve the built output

npm run format:check   # oxfmt --check
npm run lint           # oxlint
npm run typecheck      # astro check
```
